# whitneydelyse.com

Portfolio site for Whitney Delyse Smith. Plain static HTML/CSS, no build step.

- `index.html` homepage, one folder per page (`/about/`, `/making-fetch-happen/`, …)
- `site.css` shared styles, `site.js` sliders / video / collage scaling
- `img/` images, `fonts/` self-hosted Archivo, Instrument Serif, Caveat (SIL OFL)
- Hosted on Netlify (`netlify.toml`); publish directory is the repo root.
